# Adamantine-
A mod for the Mineclonia game in Luanti which adds a teir above Netherite made using a overworld ore rarer than Diamonds named Adamantine.
## Credits

The optional CraftoPlus integration (placeable ingots, and the adamantine chain,
door, double door, ladder, bars, trapdoor and carved block) is based on the gold
items from [CraftoPlus](https://content.luanti.org/packages/Mish7913/craftoplus/)
by Mish7913. Code and textures are used under the GNU GPL v3 or later; the
textures are recolored to adamantine in code.
These items only appear when CraftoPlus (and its dependency m7a) is installed.
