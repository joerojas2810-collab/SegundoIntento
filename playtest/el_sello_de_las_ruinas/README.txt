EL SELLO DE LAS RUINAS — mundo preparado

No edites el mapa a mano. El mod zz_sello_ruins construye una sola vez el
campamento, el sendero, la fortaleza y la cripta cuando abres el mundo. En
arranques posteriores conserva todo lo que hayas cambiado.

Abre este mundo con el juego Everforge (gameid everforge):
  luanti --gameid everforge --world <ruta>/playtest/el_sello_de_las_ruinas

En macOS, usa el archivo «Jugar El Sello de las Ruinas.command» de la raíz del
repositorio.
